## Conventions used in the docs

- Addresses like `FUN_08322504` or `VA 0x014915e8` are Ghidra function or
  virtual addresses in the named binary (NavCore, MMI3GNavigation,
  vdev-logvolmgr for 3G Plus; libPathfinderApp.so for MIB). Image bases are
  stated in each doc.
- `out/<name>/report.json` is the report of the tool with the same name. The
  `out/` directory is not committed; the reports are regenerated by running
  the tools against your own inputs.
- "Proven" means: the claim was checked by a script over the full corpus
  with zero failures, and usually also by a byte-identical round-trip.
  "Candidate" and "open" mean exactly that.
